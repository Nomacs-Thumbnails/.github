# nomacs - View Pictures You Are Allowed to Open

nomacs browses images in a folder you choose and opens one picture at a time. Viewing should not change the file. If you crop or export, write a new name and leave the original. It does not include a stock library, and a folder on a shared drive is not yours just because you can see the path.

---

## Why It Stands Out

![nomacs showing one photo from a folder the user is allowed to open](https://cdn.neowin.com/news/images/uploaded/2015/04/nomacs_screenshot.jpg)

Thumbnails answer "what is in this shoot" faster than opening every file in an editor. nomacs is that pass: a directory you pick, a larger view, and the next image. Fit-to-window shows the whole frame. Actual size shows whether the photo is sharp. Those are ways of looking. They are not a retouch.

The risk is a save. A viewer that can also write will overwrite a camera file if you confirm the same name. Read the dialog. The original name stays the master until you choose a different one. Delete only through the recycle bin, and only after you know that path works, and only for files you have backed up. Close the window when you leave a shared PC if the pictures are private.

---

## Core Capabilities

- **A Folder You Open:** Thumbnails of images you may view.
- **Next and Previous:** Step through that directory without a heavy editor.
- **Actual Size:** Check sharpness at 100 percent before you call a photo soft.
- **A New Name If You Export:** A crop or a convert is a second file.
- **Leave the Date Alone:** Looking should not rewrite the original.

---

## Performance Tips

- Open the real folder, not a shortcut you do not trust.
- Switch between fit and actual size on one photo before you judge the shoot.
- Save exports beside the original, not on top of it.
- Do not delete from a card you have not copied.

## Quick Setup

Prerequisites: A folder of images you may view, and no plan to overwrite them on the first open.

2.  **Open One Photo:** Look at fit and at actual size.
3.  **Step Once:** Next and previous should stay in that folder.
4.  **Close Without Saving:** Check in Explorer that the file date did not change.

---

## Troubleshooting

- Thumbnails are blank? You opened the wrong folder, or the files are not images nomacs reads. Do not convert the originals to find out.
- The picture looks soft? Switch to actual size. Fit-to-window is not the pixels.
- Explorer shows a new time on the file? You saved. Restore the original from the copy you should have kept.
- A folder is not yours? Close it.
